## Sobre este proyecto
This project was born for two reasons: I was playing WoW, and midudev uploaded a reel showcasing Pragmatic Drag and Drop, which made me want to try something with that technology. Since I needed a tool to manage my raid members and keep their information organized, I decided to combine Pragmatic Drag and Drop with standard technologies like React. I also wanted a framework with convenient, beautiful, and easy-to-use components, which led me to choose ChakraUI. It is a small project that I still use today.

### Características principales
- Data persistence using localStorage. (Or: Saving data locally via localStorage.)
- Powered by Atlassian's Pragmatic Drag and Drop. (Or: Main feature built with Atlassian's Pragmatic Drag and Drop.)
